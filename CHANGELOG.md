# Changelog

## 1.0.0

First release.

- Local music library with Home, Songs, Library and search
- Playlists with custom covers, liked songs, recently played and On Repeat
- Now Playing with album-art colours, queue, swipe to skip and several seek bar styles
- Equalizer, bass boost, virtualizer, playback speed and pitch, sleep timer
- Optional tag lookup via MusicBrainz, written to MP3 and M4A files after approval
- Light, dark and follow-device themes, customizable app icon
